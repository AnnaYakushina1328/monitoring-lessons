# Мониторинг учебных занятий

Веб-платформа для планирования и проведения мониторинга учебных занятий.

## Технологии

- Python
- Django 5.2 LTS
- PostgreSQL
- Docker Compose

## Локальный запуск

1. Создать `.env` на основе `.env.example`.
2. Запустить:

```bash
docker compose up --build
3. Открыть:
http://localhost:8000
